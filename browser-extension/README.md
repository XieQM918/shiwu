# 日常Chrome连接扩展

此扩展供本机拾物工作台使用。它使用当前Chrome已经登录的ChatGPT，避免另建浏览器资料反复登录。Mac与Windows使用同一份扩展。初次安装须本人审核权限并手动操作。

1. 工作台打开“环境检查”或生图面板的“浏览器接入设置”。下载扩展ZIP并解压，或直接使用工程的 `browser-extension` 文件夹。
2. 日常Chrome打开 `chrome://extensions`，开启“开发者模式”，选择“加载已解压的扩展程序”，选中包含manifest.json的文件夹。
3. 点击工具栏扩展“拾物 ChatGPT 连接”。从工作台复制本机连接码，粘贴到扩展；工作台地址填写当前本机地址，例如 `http://127.0.0.1:3210`。点击连接。
4. 工作台确认“已连接日常Chrome”，再点击当前生图任务的“继续 / 重试”。首次接收最长约30秒。扩展只在有工作台任务时新建ChatGPT标签页。

需要的权限：ChatGPT页面脚本操作、扩展自身设置、30秒连接检查、下载文件的登记。仅声明ChatGPT与本机127.0.0.1的站点访问权限，不声明Google登录页面或所有网站访问权限。不读取密码、Cookie或登录令牌，不操作验证码。配对码只用于本机服务，不是GPT账号凭据。

每张任务冻结原图和提示词。发送前记录任务编号及模型，成功后保存原会话地址。服务重启或停止不自动再次发送；不能确认原会话时暂停。缺少背面、侧面依据的场景跳过。

使用页面原图下载按钮。只有能明确关联本次会话的图片下载，才登记到 `Downloads/shiwu-results/<任务编号>/`；服务只读取该登记目录，不扫描或导入其他下载。Chrome默认下载目录若已改动，请为该次下载选择系统用户Downloads目录。文件同时保留在Chrome下载目录与工作台成品目录，不自动删除下载副本。

状态说明：已配对不等于网页已具备生图权限；每张提交前检查GPT-5.6 Sol。登录、验证、网页变化、额度限制、无法关联下载时均暂停，不回退Codex或付费API。网页不提供官方单图token明细，不代表零消耗。

当前验证：隔离HTTP和Chrome内容脚本测试通过；真实扩展安装、会员生图和原图回传须安装配对后另行验收。

## 1.0.3 原生交互权限

旧版脚本触发未通过真实ChatGPT页面验证。1.0.3使用Chrome debugger API提供的原生鼠标、文本输入和已登记原图上传能力。该权限不能设为可选权限，更新时须本人审核并重新启用。Chrome授予的调试能力范围较广；本扩展代码只对工作台分配的ChatGPT任务标签页附加，命令限定为输入事件和已登记原图的上传，不执行任意脚本、网络读取或Cookie操作。不访问Google登录页、Chrome内部设置或其他标签页。Chrome显示的调试提示条不隐藏，取消即暂停任务。

使用时不要同时在生图标签页打开开发者工具或其他自动化控制；若已被其他调试器占用，会暂停而非强制接管。
