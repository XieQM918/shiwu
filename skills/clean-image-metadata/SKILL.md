# 图片来源元数据清理

输入为用户选中或明确提供的本地文件夹。若上下文没有可用路径，只询问路径，不猜测当前目录就是输入。

执行本 Skill 的 `scripts/clean_metadata.py INPUT_DIR`，用可用的 Python 3 运行。仅在用户明确要求“清理后复查”时添加 `--verify`。脚本只依赖 Python 标准库和 PATH 中的 ExifTool；缺少 ExifTool 时报告依赖缺失，不静默安装。

默认递归处理静态 JPEG、PNG、WebP，在输入目录旁生成独立的 `原目录名_cleaned_时间戳` 目录，保留文件名、层级和原图。隐藏目录、符号链接、历史输出、动画及检测出的特殊显示结构跳过。只复制处理的图片，不复制其他文件。

广泛清理工具支持删除的元数据，保留 ICC、方向和颜色显示信息；不压缩、缩放、补写拍摄来源。默认只检查逐文件工具状态与输出存在且非空，不追加元数据扫描、解码或哈希。不要因惯常审计习惯增加逐张验证或反复重试。

脚本 stdout 返回 JSON 摘要，输出目录内 `处理报告.json` 保存计数与异常文件清单，不保存原始元数据值。退出码 0 表示无失败（可能有跳过/警告），1 表示部分失败，2 表示任务级错误；部分失败时仍交付成功结果。异常副本由脚本移除。

回复提供输出目录链接和成功、跳过、失败数量，有警告时简述。默认说“处理完成”；只有启用复查才说明“已复查”，并披露未通过的文件。复查仅覆盖脚本定义的描述/来源字段和来源块，不表示文件内所有信息均已消失。任何模式均不承诺去除像素隐形水印、无法识别为 AI 或通过平台检测。

用户请求清理已经授权创建输出副本，无须例行再次确认；受限目录仍遵守实际环境的文件访问审批。自动调用不表示后台监控。
