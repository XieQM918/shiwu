# Etsy 饰品场景出图

以真实商品为基础，生成自然、克制、接近实拍的商品摄影。新商品素材决定商品事实，旧成品图只指导摄影风格。用户本次要求优先于本 skill 的默认值。

## 1. 读取输入并锁定商品

接受图片、参数截图和自然语言，无需用户填写模板。先查看所有相关商品图片，整理简短事实清单：

- 具体品类、佩戴或固定方式；区分耳垂耳夹、耳骨夹与穿孔耳饰。
- 本次款式及颜色，轮廓、装饰数量与位置、连接结构、正反面证据。
- 长宽厚度、链长或绳长；区分主体尺寸与含连接件总长。
- 重量及其口径：单件、一对或整套；材质与售卖数量。
- 用户指定场景、配色、肤色、比例与每场景候选数量。

明确已确认和未知的信息。图片与文字冲突时先澄清；缺少影响尺度或佩戴的关键尺寸、固定方式时集中补问。非关键缺项不阻止已有证据支持的场景。不能仅凭外观认定贵金属、天然珍珠或手工属性。

每张图锁定同一商品的颜色、数量、比例、纹理和结构。未知背面、扣件不补造，未知材质不升级。重量仅辅助判断悬挂状态，不能单独推算软硬或精确形变。生成图不宣称毫米级尺度准确。

## 2. 选择场景与风格

读取 [品类场景与摄影指南](references/scene-guide.md)，按品类查看该指南列出的本地风格参考图。参考图不是新商品结构或尺寸的依据。

默认四组，每组3张独立候选，共12张：

1. 使用主图：实际佩戴或连接场景，主体突出，保留必要使用关系。
2. 完整外观：清楚交代完整轮廓与实际售卖数量。
3. 不同角度：展示立体厚度或有证据的固定结构，不能仅换背景。耳夹优先利用此组展示夹口与接触部件。
4. 手持尺度参照：保持相对人体的可信大小，关键部位不被手指遮挡。

用户指定精简时每组2张；明确指定的数量和场景优先。微距、背面、第二搭配等额外组仅在素材支持且用户需要时增加，不自动扩展。无法支持某组时说明原因，改用已知视角中有明确展示价值的方案；无合理替代则说明缺口，不凑图。

默认方形、无文字、无装饰边框、无额外品牌标识；不添加未包含在售卖内容中的包装。方形是店铺默认值，不是平台规格声明。展示简短的场景与数量清单后直接执行，事实齐全时无需另设审批。

## 3. 真实感与候选变化

- 通过裁切与镜头突出商品，不放大商品相对人体或包身的比例。面部只保留解释佩戴所需部分，不强制露出完整半张脸。
- 近景皮肤保留适量毛孔、轻微色素点、绒毛和自然肤色差异，手部保留掌纹、指节褶皱及自然指甲。细节强度匹配距离，不磨皮成蜡像，也不夸大斑点或毛孔。
- 金属保留明暗过渡与环境反射；织物保留织纹与褶皱；编织保留针脚、起伏和适量毛感。不通过给商品添加划痕、缺陷或虚构工艺制造真实感。
- 光线有方向，接触阴影、反射、遮挡和重力一致。检查耳夹贴合、胸针附着、挂绳连接，避免悬浮、穿透、错误佩戴。
- 每组候选保持相同任务与整体风格，适度改变角度、裁切、姿态或光向。完整外观、背面与微距属于不同信息任务，不能冒充同一组的三个可互选版本。

## 4. 逐张生成与检查

使用内置图片生成工具，按可用 imagegen skill 的工作方式操作；不以代码绘图代替商品摄影，不擅自切换收费API或CLI。每张候选独立生成，不能用一张拼图代替多张原图。

每次调用都明确传入原始商品参考及不可改变的参数；不能只依赖前一张生成图。分别标注商品事实参考与风格参考的角色。使用本地图片前先查看，引用方式遵循当前工具接口，不虚构参数。

每张提示词应包含：商品与参考角色、场景及展示任务、构图与候选变化、光线和配色、具体材质与皮肤细节、真实尺寸口径、必须保留的结构、需要避免的错误。重点写具体约束，不堆叠抽象的“超真实”形容词。

生成后实际查看并检查：

1. 商品是否与原始素材一致，颜色、装饰数量和连接件是否变化。
2. 尺度、解剖、夹持或悬挂关系是否可信。
3. 是否过度磨皮、反光过曝、边缘融化或材质失真。
4. 是否完成该组任务，候选是否存在有意义的差异。

有明显问题的候选最多定向修正两次，每次重申原始商品约束。仍不合格则说明缺口和原因，不列为合格交付。工具受限或中断时保留已完成结果，报告实际完成数量，不宣称已完成检查不到的图片。

## 5. 保存与交付

将最终图片复制到当前项目的 `output/etsy-accessory-images/<商品名>/<批次>/`，使用新的批次目录避免覆盖。沿用工具实际返回的文件格式，不只改后缀。

文件按场景及候选编号命名，例如 `01-use-A.png`、`02-overview-B.png`。独立原图必须保留；可选联系表仅供比较，不能替代原图。

按场景展示或链接合格图片，标注A/B/C、推荐候选与一句选择理由。简要报告合格数量及未解决问题。审核失败图片如需保留，应放入单独的待修正目录，不混入合格候选。无需附冗长的技术过程。
