# 品类场景与摄影指南

## 场景选择表

| 品类 | 使用主图 | 辅图重点与限制 |
|---|---|---|
| 耳夹、耳饰 | 耳部近景，保留必要脸颊与下颌，头发避开商品 | 指尖、掌心、单只或成对静物；按实际结构显示夹口、接触垫或耳针，耳夹不得变成穿孔耳饰 |
| 胸针 | 西装翻领、针织衫或外套局部 | 掌心、亚麻或绒布、斜侧层次；背针须有背面证据，衣料与重量和固定方式相适应 |
| 包挂 | 局部包身和实际连接位置 | 帆布包或皮包、平铺、手持、绳结与编织细节；锁定主体尺寸、总长、各部件相对位置 |
| 项链、吊坠 | 颈部、锁骨或胸前局部，按链长取景 | 完整链条、手托吊坠、斜侧与扣头；不缩短链条或放大吊坠来适应构图 |
| 手链、手镯 | 手腕局部与自然手势 | 外观、扣件、珠饰排列和侧面厚度；保持松紧合理，避免其他叠戴饰品干扰 |
| 戒指 | 手指佩戴近景 | 指尖、戒面、戒圈与开口；保持戒面相对手指的尺度 |
| 发饰 | 发侧或后脑局部，匹配固定方式 | 手持、平铺、夹齿与背部；发型与尺寸重量适配，不遮主要装饰 |
| 钥匙扣、手机挂饰 | 实际连接物件的局部场景 | 手持、完整平铺、连接件与绳结；不能虚构挂点或扩展用途 |

未列品类按实际使用方式、固定结构、尺度参照、材质细节选择。延伸用途必须有依据，尤其不能因包挂参考图出现窗帘绑饰，就为其他商品生成窗帘用途。

## 配色、光线与质感

统一摄影语言，不要求统一背景。根据商品辨识度选择：

- 深色衬托：黑色服装、墨绿织物等突出浅色花瓣与金属细节，暗部仍保留纹理。
- 浅色自然：奶油白、米色、暖石色，柔和光线与轻微阴影，衬托植物造型和细腻表面。
- 暖色金属：金色与奶油米色、自然肤色搭配，方向性光线让弧面有明暗层次；暖调不能把实际颜色染黄。
- 明亮生活：帆布、皮革、亚麻、木材和窗边光线，突出编织纱线与日常使用感，背景不抢主体。

柔和不等于没有阴影。可用有方向的窗光，保持阴影边缘、反射和高光一致。完整外观图关键结构清楚；微距允许浅景深，但展示目标清晰。静物立放必须有合理支撑。

皮肤的毛孔、微小色素点和细绒毛应随取景距离自然可见，不使用统一颗粒覆盖代替真实纹理。商品不添加虚构的磨损；材质忠实于本次参数，不将照片观感当作材质鉴定。

## 规则验收用例

仅做规则检查时不调用图片生成工具，不声称完成实图测试。

1. 耳夹输入含尺寸、重量、正面及夹口素材：应安排耳部主图、成对外观、夹口斜侧、掌心四组各3张。皮肤有自然纹理，不能出现穿耳针。售卖数量若为单只则外观组不展示一对。
2. 胸针输入含尺寸及正面但无背面：应选择已知正面与有证据的斜侧，不生成背针；若无斜侧依据，应说明缺口并选择有信息价值的已知视角。背景变化不改变商品色彩。
3. 包挂输入含主体尺寸与总长：主图保留挂点，锁定花朵、草莓、绳长关系；无需用户要求不添加窗帘用途。每组独立生成3张，精简要求时改为2张。

实际出图验收另外检查：数量、候选差异、同款一致性、尺度与连接关系，以及每张图片是否真正经过查看。
